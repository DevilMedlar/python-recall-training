# Challenge 05 — Variable reuse mixed with blank-line recall

## Why this challenge exists

Challenge 04 was your first clean use of a variable, assignment, and reuse. Before adding another Python idea, this challenge mixes that new skill with the earlier empty `print()` distinction.

No new Python syntax is introduced here.

## Your task

Create this learner file yourself:

`stages/01-foundations/challenge_05.py`

From memory, write a Python program that produces exactly this output:

```text
Precision first.
Recall second.

Precision first.
Recall second.
```

### Requirements

1. Create exactly two variables.
2. Assign the string `Precision first.` to one variable exactly once.
3. Assign the string `Recall second.` to the other variable exactly once.
4. Use exactly two string literals in the entire program.
5. Use exactly five `print()` calls.
6. Use exactly one empty `print()` call to create the required blank line.
7. Every non-empty `print()` call must print a variable, not a string literal directly.
8. Reuse each variable so each stored string is printed twice.
9. Match capitalization, spaces, punctuation, blank line, and order exactly.
10. Do not use `input()`.
11. Do not add extra output.
12. Type the program yourself rather than copying a completed passing solution.
13. Commit the learner file to the repository when finished.

When the committed attempt is ready for grading, say `done`.
