# Challenge 08 — Two inputs and reverse recall

No new Python syntax is introduced here.

Create `stages/01-foundations/challenge_08.py`.

Ask for two words using these exact prompts:

`First word: `

`Second word: `

Store each answer in a different variable. After both inputs, print one blank line, then print the second stored word followed by the first stored word.

Requirements:

1. Exactly two variables.
2. Exactly two `input()` calls.
3. Each `input()` result stored in a different variable.
4. Exactly two string literals total: the two prompt strings.
5. Exactly three `print()` calls.
6. Exactly one empty `print()` call after both inputs.
7. The other two `print()` calls print variables.
8. Print the second stored word first, then the first stored word.
9. Do not reassign either variable.
10. Match prompt capitalization, punctuation, and trailing spaces exactly.
11. No extra output.
12. No concatenation, f-strings, conversion functions, or other untaught features.
13. Type the program yourself rather than copying a completed passing solution.
14. Commit the learner file when finished and say `done`.
