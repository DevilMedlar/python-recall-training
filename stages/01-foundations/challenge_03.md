# Challenge 03 — Precision recall with blank lines

## Why this challenge exists

Challenge 02 showed one small habit: using a string containing no text when the requirement specifically asked for an empty `print()` call.

You repaired it correctly. This challenge gives that distinction one fresh retrieval rep in a different arrangement before the curriculum moves on.

No new Python syntax is introduced here.

## Your task

Create this learner file yourself:

`stages/01-foundations/challenge_03.py`

From memory, write a Python program that produces exactly this output:

```text
First I recall.

Then I type.
Then I check.

Then I commit.
```

### Requirements

1. Use exactly six `print()` calls.
2. Use exactly two empty `print()` calls to create the two required blank lines.
3. Each non-empty `print()` call must print one complete required text line.
4. Match capitalization, spaces, punctuation, blank lines, and order exactly.
5. Do not use variables.
6. Do not use `input()`.
7. Do not add extra output.
8. Type the program yourself rather than copying a completed passing solution.
9. Commit the learner file to the repository when finished.

When the committed attempt is ready for grading, say `done`.
