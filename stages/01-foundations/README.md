## Lesson 1 — `print()` and string output

`print()` tells Python to display a value as output.

A simple example is:

```python
print("Hello")
```

In that statement:

- `print` is the function being called.
- The parentheses contain what should be displayed.
- `"Hello"` is a string: text surrounded by quotation marks.
- The quotation marks mark the string in the Python source; they are not printed as part of the output.
- Python is case-sensitive, and exact spaces, capitalization, and punctuation matter when exact output is required.

For this first challenge, only `print()` with string literals is required. No variables, input, arithmetic, or other Python features are needed yet.
