# Challenge 02 — `print()` with a deliberate blank line

## Tiny lesson first

You already used `print("text")` to display a string.

`print()` with nothing inside the parentheses prints a blank line.

Example:

```python
print("Above")
print()
print("Below")
```

That produces:

```text
Above

Below
```

For this challenge, that empty `print()` call is the only new syntax.

## Your task

`stages/01-foundations/challenge_02.py`

