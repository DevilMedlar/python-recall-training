# Stage 04 - Challenge 02

Use only what has already been taught: `print()`, quoted string literals, variables, assignment/reassignment, and `input()`.

## Requirements

1. Create exactly one variable named `reply`.
2. Use `input()` with the exact prompt `Favorite color: ` including the final space.
3. Store that first input result in `reply`.
4. Print `reply`.
5. Reassign the same variable `reply` using a second `input()` call with the exact prompt `Favorite food: ` including the final space.
6. Print `reply` again after the reassignment.
7. Use exactly two `input()` calls total.
8. Use exactly two `print()` calls total.
9. Do not create any other variables.
10. Do not add any extra output.
11. Type the Python yourself from memory.

## Example interaction

If the user types `blue` and then `pizza`, the interaction should look like:

```text
Favorite color: blue
blue
Favorite food: pizza
pizza
```

Write the solution in `challenge_02.py`, commit it, then tell Senpai `done`.
