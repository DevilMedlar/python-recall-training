# Stage 02 - Variables and Assignment

## Goal

Learn how Python gives a name to a value, then use that name later.

## Tiny lesson

A **variable** is a name that refers to a value.

Assignment uses a single equals sign:

```python
name = "Alex"
```

That does not mean "name equals Alex" as a math statement. It means: store the string `"Alex"` under the name `name`.

You can then use the variable in `print()`:

```python
print(name)
```

Python prints the value stored in the variable, not the variable name itself.

Variable names are case-sensitive, so `name` and `Name` are different names.
