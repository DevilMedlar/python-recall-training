# Stage 01 - `print()` and String Output

## Goal

Build the first real Python habit from memory: make Python display exact text.

## Tiny lesson

Python runs statements in order from top to bottom.

`print()` is a built-in Python function that displays output.

Text in Python is a **string**. A simple string literal is written inside matching quotation marks.

Examples:

```python
print("Moon")
print('Python')
```

Both examples print text. The quotation marks define the string; they are not normally displayed as part of the output.

For this challenge, use only the tools taught above. Do not use variables, `input()`, concatenation, f-strings, or anything else yet.
