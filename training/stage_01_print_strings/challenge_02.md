# Stage 01 - Challenge 02

## Goal

Prove the first clean `print()` pass was recall, not a lucky copy-pattern.

Use only what has already been taught: `print()` and basic quoted string literals.

## Required output

Your program must output exactly:

```text
Memory first.
Syntax second.
Output third!
```

## Requirements

1. Use exactly **three** `print()` calls.
2. The three output lines must match exactly, including capitalization and punctuation.
3. Use at least one **double-quoted** string literal.
4. Use at least one **single-quoted** string literal.
5. Do not create variables.
6. Do not use `input()`.
7. Do not add extra output.
8. Type the solution yourself from memory.

## Submission

Write your attempt in `challenge_02.py`, commit it to GitHub, then tell Senpai `done`.

Senpai must fetch the committed file before grading it.
